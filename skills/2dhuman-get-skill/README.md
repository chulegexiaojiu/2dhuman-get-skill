# 2DHUMAN GET-skill 使用与生成流程

## 这是什么
把已生成的猎手原画作为固定视觉锚点，结合世界观、人物经历和职业，生成同一美术体系的2D横版像素角色原画。

**显示名称：2DHUMAN GET-skill**
**调用标识：`2dhuman-get-skill`**
版本：1.0.0

风格：右向侧视、全身、写实偏风格化人体、精细像素簇、低饱和西式奇幻、简洁灰底、左上光。人物外形、职业、服装和武器可以改变，不是所有人都复制猎手。

## 安装位置与启用
全局安装目录：`C:\Users\xiex4\.agents\skills\2dhuman-get-skill`。
当前项目同时保留完整交付副本：`./2dhuman-get-skill/`。
全局安装与项目副本是独立副本；以后修改项目版本后需同步至全局目录才能影响日常调用。项目副本不放在项目的 `.agents/skills` 内，避免重复发现同名 Skill。

在 Pi 中执行 `/reload`，或开启新会话以重新发现 Skill，然后调用。不同宿主支持的图片能力不同：若当前图片工具不接受参考图，只能依据提示词描述近似风格，不能保证角色身份或风格稳定；Skill 会记录该限制。

```text
/skill:2dhuman-get-skill
根据当前目录游戏文档，生成一张战士角色图片。
采用Demo开局装备，保持猎手锚点的美术风格，输出到当前目录。
```

也可自然语言：

```text
使用 2DHUMAN GET-skill，生成这个世界观里的牧师角色。
外形由你设计，先采用朴素旅行阶段，输出一张图片和提示词。
```

在其他支持 Agent Skills 的宿主中，按该宿主的 Skill 加载方式调用；不保证同一个斜杠命令通用。

## 常用调用示例

### 新角色
```text
/skill:2dhuman-get-skill 为薇恩设计一张秘法职业原画。
使用当前游戏背景，朴素旅行装备、枯枝咒杖。
不要邪教标志，也不要复制猎手的弓箭。外形由你补齐并标为设计提案。
```

### 同一人物换装备
```text
/skill:2dhuman-get-skill 使用 ./hunter_2d_side_pixel.png 保持猎手身份，
改穿轻皮甲，其他面貌和配色保持，生成一张同风格全身图。
```

### 仅写提示词，不花费生图
```text
/skill:2dhuman-get-skill 根据以下人物背景编写同风格提示词，暂不生图：……
```

### 连续制作多位角色
```text
/skill:2dhuman-get-skill 为战士、牧师、法师各生成一张角色原画。
支持参考图的工具会对三张都直接传入固定猎手风格图，分别保存，不做多人拼图；不支持参考图的工具只能按提示词近似。
```
明确要求三张才生成三张；默认每次一张，不自动重试。

## 每次的制作流程
1. 查看固定猎手图，读取风格规范和模板。
2. 阅读当前背景，区分原文事实与新增外形提案。
3. 把故事转化成看得见的材质、剪裁、道具、磨损与姿态。
4. 保存中文依据与实际英文提示词。
5. 调用宿主的 `generate_image`。工具支持参考图时传入固定风格图；不支持时不伪造参数，并明确记录为无参考图生成。
6. 查看输出，检查视角、像素表现、人物装备与参考图的统一程度。
7. 保存生成记录；交付图片和提示词，披露偏差。

## 为什么比只重复文字更一致
有参考图能力的宿主中，后续生成有两层约束：
- 固定风格图提供画法与表现方向的视觉参照，但不能完全锁定结果。
- 固定提示词块约束镜头、构图、配色关系和排除项。

不支持参考图的宿主只能使用提示词约束，不能声称已将锚点图传给模型。

新人物只变化角色块；同人物续作还可添加身份参考。不要不断用上一张图片替换原锚点，否则风格容易逐代偏离。

**不能保证每次完全一致。** 模型变化、人物复杂度和随机生成仍会影响结果。有参考图时它与验收只能降低偏差，不是技术上的硬锁定；没有参考图时风格一致性更弱。

## 首次猎手生成过程
- 根据GDD提取猎手的森林生活、师承、保护平民背景。
- 自行补充约28岁男性、深栗短发、朴素绿衣和实用配件。
- 按用户要求由原GDD等距俯视改为横版侧视。
- 编写英文提示词，通过 `generate_image` 一次无参考图生成。
- 使用工具默认模型和尺寸，未指定seed，保存为 `hunter_2d_side_pixel.png`。
- 查看图片后作为这套美术风格锚点。
- 原设计预期后续Skill采用参考图辅助风格一致性；实际是否能传图取决于宿主工具能力。

## 边界与安全
- 本Skill不安装第三方代码，不需要额外脚本或API key；使用宿主提供的图片生成工具，费用遵循宿主规则。
- 本次创建Skill不额外生成图片，不暗中调用收费服务。
- 默认不自动下载/更新Skill，不自动切换工具，不批量重抽图。
- 不使用“废片”目录中的素材。
- 原图是精细像素风角色原画；“320×224”“24色”只是首次提示词审美目标，未做严格验证。不能当作已经可直接使用的低分辨率透明精灵。
- 若要游戏资产，需另外明确实际分辨率、透明背景、碰撞框、动作帧、色板和技术检查。
