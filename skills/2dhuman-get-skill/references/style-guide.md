# 风格规范｜2DHUMAN GET-skill v1.0

## 唯一主风格锚点
`../assets/hunter-style-anchor.png`。图片优先于泛泛的“像素风”描述。每次生成都要实际查看并传入 reference_images，不能仅在提示词中写文件名。

## 冻结的视觉方向
- 2D 横版游戏角色原画：朝右侧视，胸部可稍转向观众，眼平/躯干高度镜头，非等距俯视。
- 单人完整全身，完整武器；横向留白画布，角色约占高度80–85%，不能为了塞武器裁脚。
- 人体写实偏风格化，约6至7头身；精干或按职业改变体格，拒绝Q版大头。
- 高精细像素风：可见阶梯轮廓、像素簇塑造体积、选择性深色描边；材质用色块和局部高光区分。
- 低饱和西式奇幻，大地色体系，暗棕、灰绿、炭灰、暗米色；肤色自然。新职业可以更换主色，不要求所有人穿绿色。
- 光来自左上，亮暗方向统一；背景浅暖灰到中性灰，简洁近纯色。脚下短横向接地阴影。
- 自然待机/准备移动姿态，武器轮廓与身体尽量分离，避免强透视动作。
- 无环境场景、文字、标签、UI、边框、水印、复制角色。

## 可变项
性别、年龄、肤色、脸型、发型、职业、体型、服装剪裁、装备等级、武器与个性姿态。以上依据用户需求变化；保持的是画法和构图，不是猎手身份。

盔甲可以用于战士，但不能自动给所有角色加盔甲；袍服可以用于施法者，但不能默认每个职业都是绿色短衫。约束要尊重装备阶段。

## 不应复制的猎手专属特征
男性短栗发、绿色上衣、弓、箭袋、补丁与腰包不是通用风格。除非设计要求相同，新角色应有自己的职业轮廓和服装理由。

## 原始要求与实际效果的区别
首次提示词曾写“仿320×224、约24色、3阶阴影、最近邻放大”。这些是当时的审美目标，不是已验证技术指标。实际图呈现高精细像素角色插画，因此续作优先匹配参考图视觉密度，不硬声称严格24色、严格320×224或无抗锯齿。

不要默认做调色板量化、缩小再放大或抠图；这些会改变已确认风格。用户要求实际游戏精灵时，另行确定目标尺寸、色板、透明背景和动作帧，并做技术检查。

## 风格漂移处理
以固定锚点比较，不用上一张图替换锚点。若输出变厚涂、3D、Q版、正面或夸张高饱和，应记录偏差。单次生成不自动重试。用户确认新风格后再另建v2锚点，而不是修改v1原图。
