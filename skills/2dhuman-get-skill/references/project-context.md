# 本项目背景摘要

来源：当前项目《像素回合制战斗_设计文档_v2.docx》，内部版本v2.3.4。此文件为摘要，不替代最新原文。新项目不自动套用这些设定。

## 已确定事实
- 西式奇幻，偏暗真实色调；圣律王国为教廷王国。王国破灭后皇帝已死，教廷仍运作，余烬庇护营由教廷管辖。
- 赤扉教团秘密实施秘法歧途，企图举行降临仪式；终局大祭司为萨冯。秘法职业不等于邪教成员。
- 正篇战士为原王国守卫，获老人解救，后来守护营地民众。
- 牧师从另一王国学成，旅行救治伤民；牧师是治疗职业，不掌权，不应默认大主教。
- 法师在保卫战期间外出考取徽章，归来国破，为寻亲来到聚落。
- 猎手自幼随师，保卫战期间在附近森林狩猎，击退追赶平民的暴徒后前往聚落。
- 戈伦为狂战士，薇恩为秘法；正篇重建期间因调查邪教的秘密委托相遇。
- 正篇四人于破灭后营地相识；Demo四人取得职业徽章后在酒馆结队，调查绑架案。两套开场不能合并成同一事件。
- Demo开局朴素旅人便衣，无手套、头盔、绑腿或项链。战士：锈刃短剑、木包铁盾；狂战士：双锈刃短剑；猎手：榆木短弓、普通箭；法师/牧师/秘法：枯枝咒杖。
- 后期装备可以变化：战士板甲盾，狂战偏鳞甲双剑，猎手偏皮甲弓，施法者偏布甲杖；不得把高阶装备默认给开局角色。
